# Algorithms & Data Structures in C++

A collection of C++ implementations of fundamental **Algorithms and Data Structures**, organized for learning, practicing, and understanding core computer science concepts.

This repository is continuously updated with new implementations and examples.

## 🎯 Repository Goals

- Understand fundamental algorithms and data structures.
- Practice problem-solving using C++.
- Learn how different algorithms work through simple implementations.
- Compare algorithms based on their time and space complexity.
- Build a useful reference for students and programming beginners.

### 2. Data Structures

This section contains implementations of fundamental data structures.

#### Stack

A Stack is a linear data structure that follows the **LIFO (Last In, First Out)** principle.

| File | Description |
|---|---|
| `stack_Normal.cpp` | Basic Stack implementation using an integer array. |
| `stack_anyType.cpp` | Generic Stack implementation using C++ Templates, supporting different data types. |

**Implemented Stack Operations:**

- `Push()` - Adds an element to the top.
- `Pop()` - Removes the top element.
- `PopAndReturn()` - Removes and returns the top element.
- `Peek()` - Returns the top element without removing it.
- `isEmpty()` - Checks whether the Stack is empty.
- `isFull()` - Checks whether the Stack is full.
- `Size()` - Returns the number of elements.
- `Display()` - Displays all elements from top to bottom.

*More data structures will be added.*
