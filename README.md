### 2. Algorithms

📁 `02-Algorithms/`

This section contains implementations of fundamental algorithms, organized into categories.

#### 🔍 Searching Algorithms

📁 `Searching/`

| Algorithm | Description |
|---|---|
| Binary Search | Searches for a target element in a sorted array by repeatedly dividing the search interval in half. |

#### 🔃 Sorting Algorithms

📁 `Sorting/`

| Algorithm | Description |
|---|---|
| Bubble Sort | Repeatedly compares adjacent elements and swaps them if they are in the wrong order. |
| Insertion Sort | Builds a sorted portion by inserting each element into its correct position. |
| Merge Sort | Divides the array into smaller parts, sorts them, and merges the results. |
| Quick Sort | Sorts elements using a pivot to partition the array into smaller sections. |
| Selection Sort | Repeatedly selects the smallest element from the unsorted portion and places it in its correct position. |

[Explore Algorithms](./02-Algorithms/README.md)

### 3. Data Structures

📁 `03-Data-Structures/`

This section covers fundamental data structures and their implementations in C++.

#### Stack

📁 `stack/`

A Stack is a linear data structure that follows the **LIFO (Last In, First Out)** principle.

| File | Description |
|---|---|
| `stack_Normal.cpp` | Basic Stack implementation using an integer array. |
| `stack_anyType.cpp` | Generic Stack implementation using C++ Templates to support different data types. |

**Implemented Stack Operations:**
- `Push()` - Adds an element to the top.
- `Pop()` - Removes the top element.
- `PopAndReturn()` - Removes and returns the top element.
- `Peek()` - Returns the top element without removing it.
- `isEmpty()` - Checks whether the Stack is empty.
- `isFull()` - Checks whether the Stack is full.
- `Size()` - Returns the number of elements.
- `Display()` - Displays all elements from top to bottom.
